# CodeAlpha Chatbot

## Project Overview
This project is a simple web-based chatbot developed using Python and Flask. It responds to user messages by matching them with questions stored in a predefined knowledge base.

## Features
- Simple and user-friendly web interface
- Responds to greetings and predefined questions
- Answers basic questions about Python and cloud computing
- Uses Python's `difflib` library for question matching
- Displays chatbot responses on the webpage

## Technologies Used
- Python
- Flask
- HTML
- CSS

## Installation and Setup

1. Clone or download this repository.
2. Install the required dependencies:

   `pip install -r requirements.txt`

3. Run the application:

   `python app.py`

4. Open your browser and visit:

   `http://127.0.0.1:5000`

## Testing
The chatbot was tested with greetings, questions about Python, cloud computing, and other predefined messages.
